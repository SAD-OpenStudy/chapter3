"# Chen ZhiJie's Git Learning Notes" 
## 第一次Git实验总结
1. git add 的作用是：将工作目录的修改从工作区添加到暂存区，标记哪些改动需要纳入下一次提交，实现提交内容的选择性控制。
2. git commit 的作用是：将暂存区的所有改动永久保存到本地版本库，生成带唯一 SHA-1 哈希值的提交快照，包含作者、时间、提交信息，形成可追溯的版本节点。
3. git restore notes.md 的作用是：丢弃工作区中notes.md的修改，将文件还原为版本库中的最新版本，用于撤销未暂存的改动。
4. commit 与 push 的区别是：commit 是把改动保存到本地版本库，仅本地可见；push 是把本地提交上传到远程 Gitee 仓库，让其他协作者可以获取。
