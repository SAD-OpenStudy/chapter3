## Git 命令理解

### git add

作用：把**工作区**中修改后的文件，添加到**暂存区 (stage)**。 只是告诉 Git 记录这份改动、标记为待提交，并不会生成版本快照保存到仓库。 示例：`git add notes.md`

### git commit

作用：将**暂存区里所有已暂存的变更**打包，生成一条 commit 版本快照，存入本地`.git`仓库。 这个提交仅保存在本机，**不会自动上传到 Gitee 远程仓库**。 示例：`git commit -m "补充git命令笔记"`，引号内填写本次修改说明。

### git restore

1. `git restore 文件名`：丢弃工作区**还没有 add**的修改，把文件恢复成仓库中保存的版本，未暂存改动会丢失。
2. `git restore --staged 文件名`：撤销`git add`操作，将文件从暂存区撤回工作区。文件修改内容保留，只是取消待提交标记。

### commit 与 push 的区别

- `commit`：**本地操作**。在电脑本地仓库生成版本快照，远程仓库看不到这次改动。
- `push`：**远程上传操作**。把本地已经 commit 完成的版本，推送到 Gitee 远程仓库，同步给团队。

> 逻辑顺序：必须先执行 commit 生成本地版本，才能执行 push 上传到远程。commit 是本地存档，push 是同步到服务器。
