## 第一次Git实验总结

1. `git add` 的作用是：将工作区中的修改添加到暂存区，表示这些修改准备进入下一次提交。

2. `git commit` 的作用是：将暂存区中的内容保存为本地仓库中的一次正式提交，并生成一个可追溯的版本节点。

3. `git restore 文件名` 的作用是：恢复工作区中的文件内容。默认情况下会用暂存区或最近提交中的版本覆盖当前工作区对应文件。

4. `commit` 与 `push` 的区别是：
   - `commit` 是把修改保存到本地 Git 仓库中，只在本机可见；
   - `push` 是把本地仓库中的提交上传到远程仓库，例如 GitHub，让其他人可以获取这些提交。
